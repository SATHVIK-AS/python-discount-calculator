# python-discount-calculator
Python Discount Calculator<b>
<br>
A simple beginner-friendly Python program that calculates the total purchase amount and applies a discount based on the total value. <br><br>
This project was created as part of my Python learning journey and to practice using Git and GitHub, including creating repositories, writing README files, making commits, and pushing code to GitHub.
<br>
Features <br>
 - Takes customer name as input <br>
 - Takes item price and quantity <br>
 - Calculates the total amount<br>
 - Applies different discount rates<br>
 - Calculates the final amount after discount<br>
 - Uses Python if, elif, and else conditions<br>
